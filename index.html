MATHEMATICAL TRICKS AND COGNITIVE SHORTCUTS FOR SPEED QUANT INTERVIEWS

ROW 1: Left-to-Right Execution (Speed Addition)
Concept: Do not calculate right-to-left. Process the highest place values first.
Example: 674 + 258 -> 600+200=800 -> 800+70+50=920 -> 920+4+8=932.
ROW 2: Reciprocal Doubling (Division by 5/25)
Concept: To divide by 5, multiply the value by 2 and shift the decimal point 1 place to the left.
Example: 315 / 5 -> (315 * 2) / 10 -> 630 / 10 = 63.
ROW 3: Constant Difference (No-Borrow Subtraction)
Concept: Add/subtract identical values to both integers to make the subtrahend a multiple of 10.
Example: 83 - 47 -> Add 3 to both -> 86 - 50 = 36.
ROW 1: The Crisscross Method (2x2 Multiplications)
Concept: Single-line execution for AB * CD.
Steps: 1. Units (B*D) | 2. Cross-Sum (A*D + B*C) | 3. Tens (A*C). Carry over values sequentially.
Example: 23 * 45 -> (3*5=15, keep 5, carry 1) -> (2*5 + 3*4 + 1 = 23, keep 3, carry 2) -> (2*4 + 2 = 10) -> Total: 1035.
ROW 2: Difference of Squares
Concept: For numbers balancing equidistant from a round base, apply: (x-y)(x+y) = x^2 - y^2.
Example: 43 * 37 -> (40 + 3)(40 - 3) -> 40^2 - 3^2 -> 1600 - 9 = 1591.
ROW 3: Squaring Base-5 Numbers
Concept: Any number ending in 5 squared (A5 * A5) always ends in 25. The prefix is A * (A + 1).
Example: 75 * 75 -> Prefix = 7 * 8 = 56 -> Appended result = 5625.
